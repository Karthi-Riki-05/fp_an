Quick start

Read your stops in 3 steps. You need an API key from FP → Integrations.

1. Call the API with your key
curl https://api.fp.example/v1/stops?since=2026-10-22 \ -H "Authorization: Bearer fpk_live_…"
2. You get a list of stops
{ "data": [ { "machine": "K-5", "start": "2026-10-22T06:12:30+02:00", "minutes": 41.7, "reason": "Material wait" } ] }
3. Ask for more with the cursor

Lists return 100 at a time. Use next to get the next page.
